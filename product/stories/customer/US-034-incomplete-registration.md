# US-034 — Incomplete Registration Recovery

## Intent

As a user, I want to resume a registration I didn't finish, so that I don't have to start over from scratch.

## Value

Respects the user's time and effort. Interruptions are normal — the system should accommodate them without penalty, preserving whatever progress was already made.

## Acceptance Criteria

- User can return and continue a previously started registration
- Previously entered information is preserved where possible
- The system does not penalize the user for leaving mid-flow
- User understands where they are in the process upon return
- No data is silently lost or discarded

## Emotional Guarantees

- EG-04 Forgiving of interruption
